# Amrit Bhusal — Personal Portfolio

A responsive, single-page personal portfolio built with plain HTML, CSS and JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

No build tools or package installation are required.

## Before publishing — important edits
Open `index.html` and replace these placeholders:
- `REPLACE-WITH-YOUR-USERNAME` with your GitHub username.
- `REPLACE-WITH-REPOSITORY` with the Student Management System repository name.
- `REPLACE-WITH-YOUR-LINKEDIN` with your LinkedIn profile slug.
- `YOUR-EMAIL@example.com` with your professional email address.

Also verify:
- Your exact education wording and current status.
- Your RestroHub job title, start date and responsibilities.
- The technologies listed under skills reflect what you can comfortably discuss in an interview.

## Publish with GitHub Pages
1. Create a new public GitHub repository, for example `amrit-portfolio`.
2. Upload `index.html`, `style.css`, `script.js` and this README to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. The URL will appear in the Pages settings.

## Notes
- The site uses Google Fonts, so the font styling requires an internet connection.
- The portfolio intentionally describes skills as learning/practical-level rather than claiming expert proficiency.
- Do not publish passwords, `.env` files, database credentials, private keys or other secrets.
